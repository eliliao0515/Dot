Privacy Policy

Last updated: 2026-10-04

This page explains how "Dot" (Traditional Chinese name: 長輩手機練習, a phone-skills sandbox simulator for elderly learners; referred to below as "the Service") handles personal data. The Service is developed and operated by 〔developer's name or handle, please fill in〕 ("the developer"), as an individual, non-commercial project — not a company or other corporate entity.

1. Nature of the Service

The Service is a sandbox simulator that teaches users aged 65 and above to recognize common phone symbols and operate the interface of a mobile messaging app, and uses points to encourage practice at workshops. Every contact, conversation, and scenario shown is scripted teaching content — none of it is a real person or a real message; using the Service never sends any message to a real human being.

2. Personal Data Collected

This section describes the actual behavior of the currently deployed version, verified against the source code.

The web version of the Service requires signing in with a LINE account (via LINE's official LIFF technology). The Service requests only the profile scope from LINE. After sign-in, the following data is collected and used:

DataPurposeWhere it is stored
LINE user IDTo recognize "the same user" so points and practice progress can be keptThe developer's Cloudflare server; the browser storage on the user's device
LINE display name, profile picture URLShown only on the Service's "Me" pageOn the user's device only; never sent to the developer's server
Points, number of quiz rounds, completed practice stepsPoints earned during workshop activitiesThe developer's Cloudflare server; the user's device
Practice progress (e.g. which stage was reached)To resume practice next timeThe browser storage on the user's device
  • All contacts and conversations shown are scripted teaching scenarios. Text the user types, voice the user records, and photos the user picks during practice exist only on the current practice screen and are never sent to any server; they disappear when the page is closed.
  • The Service does not use any web analytics, behavioral tracking, or advertising tools (e.g. Google Analytics, Meta Pixel).
  • The Service uses the browser's local storage (LocalStorage) to keep the sign-in state, practice progress, and points waiting to be sent; it is not used to track users.

5. Period, Region, Recipients, and Manner of Use

  • Period: Data on the server is kept until the user deletes it from the Service's "Me" page. Data not deleted by the user will be deleted from the server by the developer within six months after this project ends. Data on the user's device is kept at the user's discretion (clearing browser data removes it).
  • Region: The web pages are hosted on GitHub Pages (GitHub, Inc., USA). The points server uses Cloudflare, Inc.'s (USA) Workers and D1 services; data may be stored outside Taiwan.
  • Recipients: The developer. The LINE platform (LY Corporation) acts as the identity provider; Cloudflare, Inc. acts as the server provider. The developer does not provide personal data to any other third party.
  • Manner: Stored and processed electronically. The server only accepts writes from sign-ins verified with LINE, and calculates points by fixed rules on the server side.

6. Data Subject Rights

Under Article 3 of Taiwan's Personal Data Protection Act, users may request to inquire about or review their personal data, obtain copies, supplement or correct it, stop its collection, processing, or use, and have it deleted.

  • Deletion: Tapping "清除我的點數紀錄" (Clear my points record) on the "Me" page deletes all data related to that LINE account on the developer's server, as well as the points record on that device.
  • Stopping use: After signing out and clearing the points record on the "Me" page, the Service no longer holds that user's server data.
  • Other rights: For review, copies, or corrections, please contact the developer using the contact details below.

7. Consequences of Not Providing Personal Data

The web version of the Service requires signing in with LINE. Users who do not agree to sign in cannot use the Service on their own; at workshops, staff can guide them through a demonstration device instead.

8. Third-Party Services

  • LINE platform (LY Corporation): The Service verifies users through LINE's official LIFF technology; the server confirms the sign-in with LINE and obtains the user ID. LINE's handling of this data is governed by LINE's privacy policy: https://line.me/en/terms/policy/.
  • Cloudflare, Inc.: The points server runs on Cloudflare Workers with a D1 database. As a service provider, Cloudflare may log technical connection information (such as IP addresses), governed by Cloudflare's privacy policy: https://www.cloudflare.com/privacypolicy/.
  • GitHub Pages (GitHub, Inc.): The web pages are hosted on GitHub Pages. As standard practice for a hosting service, GitHub's servers may log technical connection information such as visitors' IP addresses and browser types. Such logs are generated and kept by GitHub in its own capacity as the hosting provider, not collected or held by the developer, and are governed by GitHub's privacy statement: https://docs.github.com/site-policy/privacy-policies/github-privacy-statement.

9. Minors and Users Under Guardianship

The Service is intended for people aged 65 and above. Some users may operate it with help from family members, caregivers, or volunteers because of cognitive, visual, or motor limitations. Actions performed by a helper on a user's behalf (including completing the sign-in) are treated as the user's own actions; the developer cannot and does not verify who is actually operating the device.

The Service is not specifically aimed at users under 18. If a guardian finds that a minor has used the Service and provided personal data without consent, please notify the developer using the contact details below, and the request will be handled as described in Section 6.

10. Policy Revisions

The developer reserves the right to revise this policy at any time; revisions will update the "Last updated" date at the top of this page.

If the Service later adds a leaderboard (showing other users' names and points at a workshop), a family/caregiver dashboard, or similar features, that is a material change in how data is used; the developer will update this policy before such a feature launches, notify users prominently, and obtain consent again.
