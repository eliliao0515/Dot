## 3. 符號選擇題

### 一局的流程
1. 開場：「十題，答對一題得 100 點。答錯不扣分。」→ 大按鈕「開始」
2. 每題：上方題目、下方四個大選項，點一個就作答
3. 作答後：
   - 答對：選項變綠、打勾，「+100」
   - 答錯：被選的選項變淡（不用紅色），正確答案亮起來，「答案是『返回』」
   - 1.5 秒後自動下一題（或點「下一題」）
4. 十題結束：「這一局答對 7 題，得到 700 點」，累積總點數，按鈕「再玩一次」、「回關卡」

### 兩種題型（每局各半，隨機）
| 題型 | 題目 | 四個選項 |
|---|---|---|
| 看圖選意思 | 一個大符號 | 四個意思（文字） |
| 看意思選圖 | 一句話，例如「想回到上一頁要按哪一個？」 | 四個符號 |

錯的三個選項從題庫裡隨機挑，不重複、不跟正確答案同義。

### 版面（長輩可用性）
- 四個選項排成 2×2，每格至少 72px 高，文字 ≥ 20px
- 四格用不同顏色加不同形狀小標記，色弱也分得出來。**不照抄 Kahoot 的紅藍黃綠＋三角菱形圓方**（那是 Kahoot 的商業外觀）
- 一律點一下作答，沒有拖曳

### 符號圖庫（**要你確認來源**）

你說的「Apple 常見 icons」應該是 **SF Symbols**，但它**不能用在這裡**：SF Symbols 的授權只允許用在 Apple 平台的 App 和設計稿，不能用在網頁或 Android，而且 CLAUDE.md 規定不用第三方的商標和素材。

建議改用 **Ionicons**（MIT 授權，可以商用、可以放在網頁；風格就是照 iOS 設計的）：
- 挑大約 **40 個**長輩手機上最常看到的符號，例如返回、關閉、首頁、搜尋、設定、分享、下載、垃圾桶、電話、相機、麥克風、通知、＋、⋯、Wi-Fi、電池、音量、鎖、定位……
- 圖示檔直接放進 repo（`src/content/symbols/`），**不連網下載**（離線可用），附上 MIT 授權聲明
- 每個符號的「名稱」和「按下去會怎樣」文字由我起草，**你審過才上線**（AI 界線：意思解釋錯了會教錯）

技術上：網頁版直接用 `<Image>` 顯示 SVG，不需要新增套件。

## 4. 點數

### 怎麼得點
| 動作 | 點數 |
|---|---|
| 符號選擇題答對一題 | 100 |
| 完成一局（不管答對幾題） | 50（鼓勵玩完） |
| 情境挑戰完成一個步驟（帶著做／自己做／換情境） | 100 |
| 到真手機做到（`realDevice`） | 300（這是唯一真正的成功指標，給最多） |

數字都寫在資料檔，現場可以調。

### 要存多久：**這是這一階段最大的技術決定**

你要的是「登出、過幾天都還在」。現在點數存在手機瀏覽器裡（localStorage），**做不到這一點**：
- iPhone 的 Safari 對沒有加到主畫面的網站，**7 天沒打開就會清掉**它存的資料
- 長輩換手機、換瀏覽器、在 LINE 裡打開和在 Safari 打開，都是不同的儲存空間
- 工作坊如果用共用平板，大家的點數會混在一起

所以**需要一個小伺服器**，依 LINE 帳號存點數。零成本的做法：

| 方案 | 費用 | 你要做的事 |
|---|---|---|
| **Cloudflare Workers + D1（建議）** | 免費額度：每天 10 萬次請求，工作坊用不完 | 註冊 Cloudflare 帳號，把一組 API token 設成 GitHub Secret |
| Supabase | 免費額度足夠，但 7 天沒人用會自動暫停 | 註冊 Supabase 帳號 |

安全性：前端送 LINE 的 ID token，伺服器跟 LINE 驗證過才存，別人不能冒充（`lineAuth.web.ts` 註解早就寫了要這樣做）。

### 排行榜（**要你決定**）
| 做法 | 說明 |
|---|---|
| A. 只看自己的點數 | 最簡單，不涉及別人的資料 |
| B. 工作坊排行榜 | 講師開一個「場次代碼」，學員輸入後，大螢幕顯示這一場的前幾名（顯示 LINE 名稱）。**名稱會被別人看到，要先取得同意** |

建議先做 **A**，B 留到下一階段。

### 隱私權政策要改（**你要審**）
現在的 `public/privacy.html` 寫「不蒐集任何個人資料、沒有伺服器」，**已經跟現況不符**：P1 起強制 LINE 登入，P3 起會要求麥克風權限。加上點數上伺服器後，要更新：
- 蒐集項目：LINE User ID、顯示名稱、點數、完成了哪些關卡
- 存放位置：Cloudflare（境外）
- 麥克風：只在通話練習時判斷音量，不錄音、不上傳
- 刪除方式：「我」分頁加一顆「清除我的資料」

**法律文字我只能起草，最後要你（或懂的人）確認。**
