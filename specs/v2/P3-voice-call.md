## 1. 核心想法：讓對方的台詞帶著長輩操作

長輩在通話時會卡住的不是「講話」，是**操作**：

| 真實會遇到的情況 | 要練的動作 |
|---|---|
| 不知道從哪裡打出去 | 聊天室右上角電話 → 語音通話 |
| 響鈴時以為當機、亂按 | 等對方接 |
| 聽不清楚、想讓旁邊的人一起聽 | 按擴音 |
| 臉頰碰到螢幕誤按靜音，對方說「喂？聽不到」 | 看到靜音亮著，再按一次取消 |
| 講完不知道怎麼結束 | 按紅色掛斷 |

所以「對方」不需要聽懂長輩說什麼，只要**照劇本說話**，每一句都在提示下一個動作：

```
（響鈴 3 秒）
淑芬：喂？媽？
      ……（停 4 秒，讓長輩回話，講什麼都可以）
淑芬：你那邊好小聲，你開擴音好不好？           ← 等長輩按「擴音」
淑芬：有了，聽得很清楚。爸在旁邊嗎？叫他一起聽。
      ……（停 4 秒）
淑芬：好啦，那我先去煮飯，晚點再打給你。掰掰。  ← 等長輩按紅色掛斷
```

- **不需要麥克風**：我們不聽長輩講話，只留空檔讓他講。所以也不會跳麥克風權限，維持「不索取權限」
- **對方的話一律事先寫好、人工審過**（CLAUDE.md AI 界線）
- **字幕永遠開著**，聽不清楚也看得懂（CLAUDE.md 語音原則）

### 處理「做錯」：一律放行，只是劇情跟著變

| 長輩做了什麼 | 會發生什麼 |
|---|---|
| 對方還沒叫你開擴音就掛斷 | 通話結束，聊天室出現一則「通話時間 0:12」，外殼溫和地問「要不要再打一次？」不是錯誤 |
| 不小心按到靜音 | 對方說：「喂？喂？媽，我聽不到你的聲音耶。」→ 正好練習取消靜音 |
| 一直沒按擴音 | 對方再說一次；solo 階段同時讓「卡住了」變大 |
| 響鈴時按掛斷 | 等於取消撥號，回到聊天室，可以再打 |

「靜音」劇情特別有價值：長輩真的很常臉頰碰到螢幕誤按靜音，然後以為電話壞了。

## 5. 技術做法

**分層**（沿用 P2）
- `sim/VoiceCallScreen.tsx`：純畫面（頭像、名字、狀態、計時、靜音／擴音／掛斷），只回報按了什麼
- `sim/CallMenu.tsx`：電話選單
- `shell/CallRunner.tsx`：跑劇本、播放聲音、顯示字幕和引導、判斷過關

**劇本資料**（`engine/types.ts` 新增）
```ts
type CallLine = { id: string; text: string; audio?: { mandarin?: string; taiwanese?: string } };
type CallStep =
  | { type: 'ring'; ms: number }
  | { type: 'say'; line: CallLine }
  | { type: 'pause'; ms: number }                                   // 留空檔讓長輩講話
  | { type: 'expect'; action: 'speakerOn' | 'unmute' | 'hangUp'; coach?: string; repeat?: CallLine };
type CallScript = { contact: string; steps: CallStep[]; onMuted: CallLine };  // 誤按靜音時對方說的話
```
- 「擴音」在網頁上沒辦法真的切換喇叭，所以用**音量**模擬：沒開擴音時聲音小、開了變正常，長輩真的聽得出差別
- 用 `<audio>` 播放，不用 Web Audio：iPhone 開了靜音開關時，Web Audio 會沒聲音
- 聲音要在長輩第一次點擊之後才能播，剛好「按語音通話」就是那一下

## 6. 視訊通話（還沒決定，先列選項）

| 做法 | 成本 | 缺點 |
|---|---|---|
| A. 對方畫面放一張照片＋事先錄好的聲音 | 0 元 | 看起來像當機 |
| B. 請家人或志工錄一段 10 秒的真人影片循環播放 | 0 元，只花拍攝時間 | 要找人拍；影片檔比較大 |
| C. 自己的畫面用手機前鏡頭 | 0 元 | **會跳相機權限**，違反「不索取權限」 |
| D. 自己的畫面只放灰色方塊 | 0 元 | 跟真機不像 |

我的建議是 **B＋D**，零成本、不用權限。**不建議任何 AI 影像生成**：要花錢，而且生成的人臉、動作在長輩眼中會很怪。這個等語音通話做完再決定。
