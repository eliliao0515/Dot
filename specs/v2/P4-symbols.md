## 1. 每一關的結構（四步，沿用鷹架）

| 步驟 | 畫面 | 內容 | 過關條件 |
|---|---|---|---|

## 3. 技術做法

**引擎**（`src/engine/types.ts`，只新增）
```ts
type SymbolId = 'back' | 'close' | 'home' | 'search' | 'plus' | 'menu' | 'mic' | 'camera' | 'album' | 'phone'
              | 'share' | 'download' | 'gear' | 'badge' | 'trash' | 'warning';   // 依 §2 審核結果增減
type SymbolCard = { symbol: SymbolId; name: string; meaning: string; where: string };
type SymbolQuiz = { symbol: SymbolId; choices: string[]; answer: number };
type SymbolTransfer = { screen: 'lineChat' | 'lineChatList' | 'photoViewer' | 'lineHome'; symbol: SymbolId; prompt: string };
type SymbolScript = { cards: SymbolCard[]; quiz: SymbolQuiz[]; transfer: SymbolTransfer[]; realDevice: { headline: string; steps: string[] } };
// Level 加一種：{ kind: 'symbol'; script: SymbolScript }
```

**模擬層**：LINE 畫面裡每一顆可以點的圖示都回報「點了哪一個符號」（`onAction({ type: 'tapSymbol', symbol })`）。
模擬層只回報，不判斷對錯（跟 P2 的分層一致）。

**外殼**：新增 `shell/SymbolLesson.tsx`（帶著做、自己做兩步的畫面，HIG 風格）＋ `shell/SymbolFindRunner.tsx`（transfer 的找符號疊層）。

**圖示**：補畫 `Gear`、`Warning`、`MoreH`、`MoreV`、`Phone`（話筒，不是現在的手機外框），一樣全部用 `View` 畫。
順便把 P2 留下的相機、照片圖示照真機截圖重畫（相機凸起置中、照片改空心山形）。

**進度**：沿用現有進度格式，關卡 id 當 key，不需要搬資料。
