## 建議替換的內容（中文版）

### 二、本服務蒐集之個人資料

本服務需使用 LINE 帳號登入（透過 LINE 官方 LIFF 技術），登入後蒐集與利用下列資料：

| 資料 | 用途 | 存放位置 |
|---|---|---|
| LINE 使用者識別碼（User ID） | 辨認「這是同一位使用者」，以保存點數與練習進度 | 開發者使用之 Cloudflare 伺服器；使用者裝置之瀏覽器儲存空間 |
| LINE 顯示名稱、大頭貼圖片網址 | 僅顯示在本服務「我」頁面上 | **只在使用者自己的裝置上**，不傳送至開發者伺服器 |
| 點數、玩過幾局符號選擇題、已完成哪些練習步驟 | 工作坊活動之點數累積 | 開發者使用之 Cloudflare 伺服器；使用者裝置 |
| 練習進度（例如做到第幾關） | 下次打開時接續練習 | 使用者裝置之瀏覽器儲存空間 |

**明確不蒐集：** 電子郵件、電話號碼、地址、LINE 好友清單、LINE 聊天訊息內容、位置資訊。
本服務向 LINE 申請之權限範圍僅止於 `profile`。

### 三、裝置權限的使用

| 權限 | 何時會詢問 | 怎麼使用 | 是否上傳 |
|---|---|---|---|
| 麥克風 | 在「打語音電話」練習中按下「語音通話」時 | **只判斷音量高低**（使用者有沒有在說話、說完了沒），不辨識說話內容、不錄音 | **否** |
| 相機、相簿 | 在 LINE 模擬器中按相機或照片按鈕時 | 拍攝或選取的照片只顯示在當下的練習對話中，關閉頁面即消失 | **否** |

拒絕任何權限都不影響使用其他練習內容；打電話練習在沒有麥克風權限時仍可進行。

### 四、個人資料類別總表

| 狀態 | 資料類別 |
|---|---|
| 蒐集並存放於開發者使用之伺服器 | LINE 使用者識別碼、點數、遊戲局數、已完成之練習步驟 |
| 僅存放於使用者裝置 | LINE 顯示名稱、大頭貼圖片網址、練習進度 |
| 明確排除 | 電子郵件、電話號碼、地址、LINE 好友清單、聊天訊息內容、位置資訊、錄音、照片 |

### 五、利用之期間、地區、對象及方式

- **期間：** 伺服器上的資料保存至使用者以本服務「我」頁面之「清除我的點數紀錄」刪除，或<span>〔請決定：例如本計畫結束後 X 個月內由開發者統一刪除〕</span>為止。
- **地區：** 網頁託管於 GitHub Pages（GitHub, Inc.，美國）；點數伺服器使用 Cloudflare, Inc.（美國）之 Workers 與 D1 服務，資料可能存放於台灣以外之地區。
- **對象：** 開發者。LINE 平台（LY Corporation）作為身分驗證服務提供者；Cloudflare 作為伺服器服務提供者。
- **方式：** 以電子方式儲存與處理；伺服器僅接受經 LINE 驗證之登入狀態寫入資料。

### 六、當事人權利

使用者依個人資料保護法第 3 條得行使查詢、閱覽、製給複製本、補充或更正、停止蒐集處理或利用、刪除等權利。

- **刪除：** 於本服務「我」頁面按「清除我的點數紀錄」，即會刪除開發者伺服器上與該 LINE 帳號相關之全部資料，以及該裝置上之點數紀錄。
- **其他權利：** 請透過下方聯絡方式與開發者聯繫。

### 七、不提供個人資料之影響

本服務網頁版需以 LINE 帳號登入方可使用。不同意登入者將無法使用本服務。<span>〔請確認：是否要提供不登入的替代方式，例如工作坊現場的共用帳號？〕</span>

### 八、第三方服務揭露

- **LINE 平台（LY Corporation）**：身分驗證。依 LINE 官方隱私權政策處理。
- **Cloudflare, Inc.**：點數伺服器（Workers、D1 資料庫）。依 Cloudflare 隱私權政策處理：https://www.cloudflare.com/privacypolicy/
- **GitHub Pages（GitHub, Inc.）**：網頁託管（現行內容沿用）。

### 十、政策之修訂（替換第二段）

若本服務未來新增排行榜（於工作坊現場顯示其他使用者之名稱與點數）、子女／照顧者後台等功能，屬資料利用方式之重大變更，開發者會於上線前更新本政策並重新取得使用者同意。
