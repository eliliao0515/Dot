# Dot — MVP

教長輩使用通訊軟體的沙盒模擬器。第一版做完整的一課：**傳語音訊息**。

Expo SDK 57 / React Native 0.86 / React 19。**零額外相依套件**，`npm install` 之後直接跑。

## 跑起來

```bash
npm install
npx expo start
```

然後按 `a` 進 Android 模擬器，或按 `i` 進 iOS 模擬器（需要 macOS + Xcode）。

已驗證：`npx tsc --noEmit` 無錯誤，`npx expo export --platform android` 打包成功。

想順便跑網頁版（建議拿去做社區據點測試，不用安裝）：

```bash
npx expo install react-dom react-native-web @expo/metro-runtime
npx expo start --web
```

## 一分鐘試玩路線

1. 首頁按最上面那顆大的「接著上次」
2. 開場畫面按「開始練習」
3. **帶著做**：紅圈在麥克風上，語音提示條在底部。試著只**點一下**麥克風，會出現「壓著不要放開」的中性糾正。然後長按 0.4 秒以上，放開，語音訊息就送出去了
4. **自己做**：提示消失，右下角有「卡住了，教我」。試著亂按頂欄或輸入框兩下，求助鍵會自己變大
5. **真的做**：換成阿美、換話題，完全沒有提示
6. **里程碑**：紅色畫面，叫他關掉 App 到真手機上做一次
7. **完成**：沒有分數，只說他會什麼了

首頁右上角可以切換「字太小？改大字」，整個模擬層的尺寸會跟著變。點路線圖上還沒做的關卡不會被鎖住，會給說明。

## 目錄結構

```
src/
  engine/types.ts       腳本引擎的資料結構（核心資產）
  content/lessons.ts    課程腳本 + 路線圖資料
  sim/                  被模擬的 App，純呈現、不知道課程存在
  shell/                教學外殼：路線圖、開場、里程碑、完成
  ui/                   設計 token、字級 context、純 View 畫的圖示
```

換一個 App 只要換 `sim/` 的元件加一批 `content/` 的腳本，`engine/` 和 `shell/` 不動。

## 已經處理的長輩適用性細節

- 主要按鈕最小高度 72px
- 麥克風鍵 `hitSlop: 14` 加 `pressRetentionOffset` 60px，手抖放開時滑掉不會失敗
- 長按門檻 `minMs: 400`，寫在腳本資料裡，真機測試時直接調
- Android `includeFontPadding: false`，所有 Text 明確指定 `lineHeight`，兩平台中文行高才對得起來
- 模擬層 `allowFontScaling={false}`，尺寸只由 App 內字級參數決定；外殼層放行系統縮放
- 沒有陰影，一律用描邊（低對比敏感度看得比較清楚，也避開 iOS/Android 陰影不一致）
- 引導動畫尊重 `AccessibilityInfo.isReduceMotionEnabled()`
- 錯誤路徑全部放行，沒有紅色錯誤提示、沒有失敗音效、沒有計時、沒有分數
- 沒有紅心、連續天數、寶石、排行榜

## 這一版刻意還沒做

- **語音播放**。沒有音檔，「聽我念一次」目前只切換文字狀態。台語真人錄音是核心資產，要打包進 App 不要串流
- **進度持久化**。重開就回到起點，之後接 AsyncStorage
- **iOS 畫面變體**。`Lesson` 型別預留了平台覆寫的位置，還沒實作
- 視訊、存照片、防詐三課只有路線圖節點
- 子女端、志工帶班看板

## 三個提醒

1. **第一週就去買一台入門紅米或三星 A 系列測**，模擬器測不出手指乾燥點不到、老花看不清、握持姿勢這些真正會殺死產品的問題。
2. 所有圖示都是用 `View` 畫的，**沒有使用任何第三方 App 的商標或素材**。正式版要提高保真度時，這是法務問題不是美術問題，建議同步去談官方合作。
3. 動任何新功能之前先把 `engine/types.ts` 的腳本格式定案。這份格式定得好不好，決定第二個 App 是換資料還是重寫。
